# Contributing

Thanks for contributing! Please follow these guidelines when submitting changes.

1. Fork the repository and create a feature branch.
2. Keep changes focused and use descriptive commit messages.
3. Open a Pull Request against `main` with a clear description.

README update requirement

- If you add a new CLI command, option, or any user-visible feature under `client/`, update `client/README.md` with usage examples and any migration notes before merging.

PR checklist (add to PR description)

- [ ] `client/README.md` updated with new feature documentation (if applicable).
- [ ] Examples tested locally.
- [ ] Tests added (where appropriate).

If a change is internal and doesn't affect end users, add a note in the PR explaining why no README update is required.

Maintainers: please ensure PRs comply with the README update policy described in `.github/README_UPDATE.md`.
